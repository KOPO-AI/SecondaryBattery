# 리튬이온 배터리 EIS(임피던스 분광) 데이터 (실습용 가공본)

원본: Mendeley Data, DOI **10.17632/mbv3bx847g.3** (Buchicchio et al.)
라이선스: **CC BY 4.0** — 출처 표시 의무. 정식 인용 서지는 상위 폴더 `DATASET_CARDS.md` 참조

## 파일 구성

| 파일 | 규모 | 설명 |
|---|---|---|
| `impedance_raw.csv` | 3,360행 | 다운로드 원본. 임피던스가 **복소수 문자열**(`(0.11-0.0054j)` 형태) |
| `frequencies.csv` | 14행 | 주파수 룩업 테이블 |
| `eis_long.csv` | 3,360 × 11 | long 형식. 복소수를 실수부/허수부로 분해 + 주파수 병합 |
| `eis_wide.csv` | **240 × 33** | **주 실습 파일.** 샘플당 1행(주파수별 Zre/−Zim 컬럼), 모델링 바로 가능 |
| `eis_data_dictionary.csv` | — | 컬럼 사전(prepare.py가 실제 산출 컬럼에서 자동 생성) |
| `prepare.py` | — | 재현 스크립트 |

## 재현 방법

## 교육 포인트 (실측 근거)

- **복소수 문자열 파싱**: 반드시 `complex()`를 쓸 것. 이 데이터는 허수부가 전 구간 음수라 부호가 항상 `-`이므로, `split('+')` 같은 편법이 **우연히 통과한다**. 다른 데이터에서는 곧바로 깨지는 잘못된 습관이므로 교재에서 표준 방법을 못박는다.
- **그룹 누수**: 셀이 **4개뿐**(BATTERY_ID 02·03·05·06, 04는 결번). 무작위 분할하면 같은 셀의 반복 측정이 학습·평가에 나뉜다. GroupKFold는 최대 4-fold이며, 실측 fold별 MAE가 3.85~15.66 %SOC로 **편차가 매우 크다** — 단일 점추정치를 일반화 성능으로 제시하면 안 된다.
- **long → wide 피벗**: 3,360행 long을 240샘플 × 28피처로 변환하는 과정이 실무에서 가장 흔한 형태 변환이다.
- **이 데이터로 할 수 없는 것**: SOH·RUL 추정 **불가**. 온도·용량·사이클 수·측정 일시 컬럼이 일절 없고 전부 신품 셀이라 열화 스펙트럼이 없다. SOC 추정 실습에만 사용한다.
- **온도 미기록**: EIS는 온도 의존성이 큰데 측정 온도가 기록돼 있지 않다. 실무 적용 한계로 반드시 언급할 것.
- `REPEAT_ID`의 반복 번호가 셀마다 다르다(02·03은 4~9, 05·06은 3~8). 셀 간 비교 가능한 순번이 아니라 셀 내부 식별용이다.
