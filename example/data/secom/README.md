## 파일 구성

| 파일 | 크기 | 행 x 열 | 설명 |
|---|---|---|---|
| `secom_merged.csv` | 5,309,713 B (5.06 MB) | 1567 x 593 | 라벨·타임스탬프 병합 **메인 실습 파일** |

원본 아카이브(`secom.zip`)와 압축 해제본(`secom.data`, `secom_labels.data`, `secom.names`)은 이 폴더에 두지 않는다.
`python prepare.py` 를 실행하면 UCI에서 원본을 내려받아 동일한 결과물을 재생성한다.

센서 값은 원본 텍스트 토큰을 그대로 옮겨 적었다(부동소수점 재포맷 없음). 따라서
`secom_merged.csv`를 `read_csv`로 되읽은 590열 행렬은 원본 `secom.data`와 **값이 정확히 일치한다**
(`numpy.array_equal(..., equal_nan=True)` → True, `prepare.py` 실행 시 자동 검증).

### `secom_merged.csv` 컬럼

| 컬럼 | 타입 | 설명 |
|---|---|---|
| `timestamp` | datetime | 해당 검사 시점. `2008-07-19 11:55:00` ~ `2008-10-17 06:07:00` (89일), 시간 오름차순 정렬됨 |
| `label` | int | **원본 값 그대로.** `-1` = Pass(양품), `1` = Fail(불량) |
| `fail` | int | 파생 컬럼. `label==1` → 1, 아니면 0 (sklearn 등에 바로 투입용) |
| `sensor_000` ~ `sensor_589` | float | 익명화된 센서 590개. 물리적 의미·단위 **미공개** |

수업 첫 줄은 이것으로 끝난다:

```python
import pandas as pd
df = pd.read_csv("secom_merged.csv", parse_dates=["timestamp"])
```

## 실측값 (모두 실제 파일에서 계산)

- 센서 행렬: **1567행 x 590열** (원본 `secom.data` 1567줄 전부가 정확히 590토큰)
- 라벨 분포: **Pass(-1) 1463건 / Fail(1) 104건 → 불량률 6.6369%** (불균형 약 1:14.07)
- 전체 결측률: **4.5375%** (924,530 셀 중 41,951개)
- 컬럼 결측률: 최대 **91.1934%** (`sensor_157`), 결측 0인 컬럼 **52개**, 결측률 50% 초과 **28개**
- 행 결측률: 최대 25.763%, 최소 0.678% — **결측 0인 행은 하나도 없음(1567행 전부 결측 보유)**
- **분산 0인 컬럼 116개** (전부 비결측값이 단일 상수, 전체 NaN 컬럼은 0개)
- 분산0 집합과 결측>50% 집합은 **겹치지 않음** → 제거 대상 합계 144개, 잔여 446개 센서
- 중복 행 0건, 중복 timestamp 33건, 측정 간격 중앙값 37분

### 문서 불일치 (교재에 명시할 것)

`secom.names`와 UCI 데이터셋 페이지는 모두 **591 features**라고 적고 있으나, **실제 `secom.data`는 590열**이다.
1567줄 전부를 토큰 수로 세어 확인했다(590토큰 1567줄, 다른 값 없음). 591은 라벨 컬럼을 포함한 수이거나 메타데이터 오기로 보인다.
**공개 데이터의 문서와 실물이 다를 수 있다**는 점 자체가 좋은 교육 소재다 — 문서를 믿지 말고 `df.shape`를 찍어라.

## 이 데이터로 가르칠 수 있는 것

1. **정확도 함정** — 전부 Pass로 찍어도 정확도 **93.3631%**. 불량 104건을 하나도 못 잡는 모델이 "93점"을 받는다. Recall/Precision/PR-AUC로 넘어가는 동기 부여에 최적.
2. **결측 처리** — 결측 0인 행이 아예 없으므로 `dropna()` 하면 데이터가 전멸한다. 열 기준 제거 → 대치(imputation) 순서를 자연스럽게 가르칠 수 있다.
3. **무의미 컬럼 제거** — 분산 0인 116개 컬럼. "센서가 붙어 있다고 정보가 있는 건 아니다"를 수치로 보여준다.
4. **스케일 차이** — 컬럼 표준편차가 0에 가까운 값부터 6,554(`sensor_162`)까지. 표준화 없이 거리기반 모델(KNN/SVM)을 쓰면 특정 센서가 결과를 지배한다.
5. **단변량의 한계** — `|corr(sensor, fail)|` 최대값이 **0.1558**(`sensor_059`)에 불과하다. 단일 센서 관리한계선으로는 못 잡고 다변량 모델이 필요하다는 근거.
6. **시간 드리프트 / 데이터 누수** — 월별 불량률이 22.22% → 9.19% → 2.88% → 6.13%로 크게 변한다. 시계열 데이터를 무작위 분할하면 미래 정보가 학습에 새어든다. **시간순 분할(chronological split)** 을 가르칠 실제 근거.

### 함정·주의점

- **센서의 물리적 의미가 공개되어 있지 않다.** `sensor_059`가 무엇인지 아무도 모른다. 따라서 "원인 규명"이나 "공정 물리 해석" 실습에는 쓸 수 없고, 순수 통계적 특징선택까지만 가능하다.
- `label` 부호가 직관과 반대다(`-1`이 정상, `1`이 불량). 수강생이 가장 많이 틀리는 지점이라 `fail` 컬럼을 따로 넣었다.
- 2008년 데이터다. 현재 공정 수준을 대표하지 않는다.
- `secom.names`의 베이스라인 BER 33~40%는 **거의 무작위에 가까운 성능**이다. 이 데이터로 높은 성능이 나왔다면 누수를 의심해야 한다. 과도한 기대를 심지 말 것.

## 교재 내 사용 범위 — 심화/대조 한정

이 데이터를 **이차전지 메인 실습으로 쓰면 안 되는 이유**:

1. **공정이 다르다.** 반도체 전공정(웨이퍼 단위 포토·식각·증착)이며, 이차전지의 전극 코팅·압연·조립·화성(formation) 공정과 물리적 대응 관계가 없다. 수강생이 "우리 공정"으로 오인하면 잘못된 도메인 직관이 생긴다.
2. **품질 정의가 다르다.** SECOM의 라벨은 라인 내 검사 단일 Pass/Fail이다. 이차전지의 품질은 용량·내부저항·자가방전·수명 등 **연속형 다중 지표**이고, 불량 판정도 화성 공정 이후 시간 지연을 두고 나온다. 이진 분류 하나로 환원되지 않는다.
3. **센서 해석이 불가능하다.** 익명화되어 있어 공정 엔지니어가 자기 지식을 투입할 여지가 없다. 이 교재의 대상은 **도메인 지식은 있고 코딩만 없는** 공정 엔지니어이므로, 도메인을 쓸 수 없는 데이터는 주교재로 부적합하다.

**권장 배치**: PART 2 후반 심화 파트에서 **대조군**으로 1개 세션 배정.
- 용도 A — "고차원·고결측·극단 불균형" 표준 벤치마크로서, 이차전지 데이터에서 배운 전처리 절차가 **타 산업에서도 그대로 통한다**는 일반화 확인.
- 용도 B — 이차전지 데이터와 **나란히 비교**하여 "왜 도메인 지식이 있는 데이터가 유리한가"를 체감시키는 대조 사례.
- 반드시 **"이것은 반도체 데이터다"** 를 슬라이드와 실습 노트북 첫 셀에 명시할 것.
